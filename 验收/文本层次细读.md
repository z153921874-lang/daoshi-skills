# 正文、旧注与网页校记的区分

本项目始终保留原始HTML、修订信息和提取正文。当前“正文文件”指来源页的文字层，可能夹校记，不保证全为经文。现代研读解释放在研读目录；Obsidian 的原文与解释亦分页。

## 已查明的来源层次

- 《周易》64卦合刊区分易经、彖、象，乾坤含文言；五篇传文开头的箭头导航、作者孔子/东周题署、“本作品收录于”属于网页元数据。传统署名不冒称现代学术作者定论。《杂卦》“一篇”和“校诂版”分层，蒙杂/蒙稚、随无故/随无事、亲寡旅/旅寡亲、小人道消/小人道忧不合并。
- 《道德经》所选王弼本81章仅经文计入本轮覆盖。尖括号王弼注在提取时与经文分开，合刊快照保留；不说旧注全已逐章研读。
- 《庄子》内外杂33篇的叙述声音不一。已核读“一作「搶」”“一作「薾」”、则阳[公孫衍]及(太)[大]、天运■{梨}等。注者年代在网页未明确，一律称来源页校记，不能凭格式认定古注。知北游末尾“↑True character resembles”谈UTF-8代字，明确属现代编码说明，不能作为庄子说话引用。另见《庄子文本层次与疑字》。
- 《素问》刺法、本病开头“新校正云本篇亡在王冰之前”为来源标出的校语；页中后接遗篇内容，是传承层次不同的材料。所选刺法“正氣存內，邪氣可幹”与常见记忆不同，原样保留并标疑，不擅补“不”。针解“以下文义不属，当有错简”注者年代未明，不当作黄帝岐伯对话。
- 《灵枢》经脉中的一作、构字和音注为夹注；本神==哀悲==有网页强调残留；九宫八风图题[1]是脚注标记。骨空、标本等字形构件说明不是可直接默读为两个独立经文字的词。
- 《清静经》正文和附言是两个单元。葛玄、左玄真人、正一真人附言另标，不当成同一说话者；同页竖排与横排有慾/欲、於心/其心、名謂/名為等差异。选择横排为主读本，竖排原始快照保留，不拼校定本。
- 《坐忘论》序与七阶分开。自写应用只是现代类比，不能用“泰定”“得道”作为现代心理健康等级。
- 《梅花易数》序、附录及不同起卦法各有语境，卷内疑字和算例差异见逐章笔记；软件明示约定不倒填古籍。《紫微斗数全书》所选本含简繁混排、纵向图文、断句和疑字；不为凑现代规则删改源文。

## 已落到检索的措施

`目录/source-layers.json` 对全部568个索引单元保存层次说明及已识别标记的位置。检索摘要与全文入口均返回这些说明；范围以规范化LF后的Unicode字符计算，原文哈希对应章节索引。对明确格式的自动定位只辅助回查，不把模式命中数量当作人工校勘完成量，也不承诺发现一切无标记旧注。

引用动作：先看命中的完整段落及层次记录，再选短引文；夹注如需引用，单独标“来源页校记”。有争议的字原样展示并交代疑点。不要把注记删掉后自动拼出的句子标成逐字原文。涉及无法解释的缺字、重文、脱文时如实留白，不拿模型常识补成“原文”。

本项验收范围是层次已识别、可追查、检索时可见且引用规则明确；不是证明所有底本无误。网络录入本仍有未决疑字，后续可以新增影印版本并保留两版记录。
