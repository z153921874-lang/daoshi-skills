# 庄子文本层次与疑字

2026-09-23，33篇本地文本已全文初读，均有笔记；这不是影印底本精校。

- 内、外、杂篇存在不同论述声音，不将所有篇章、人物对话一概当作庄周本人的观点或真实史事。
- 《逍遥游》《齐物论》等夹有“一作……”字形异文说明；这是注记，引用正文时应跳过并另标异文，不把注记拼成古人句子。
- 多篇含圆括号、方括号替换或补字，例如《则阳》“犀首[公孫衍]”“(太)[大]澤”。版本录入未始终明确注者和年代，标为“来源页校记，年代未核”，不自行称为古注。
- 《天运》“柤■{梨}橘柚”含缺字及补字标记。原样保留，具体用字待影印本核验。
- 《知北游》末尾从“↑True character resembles”开始的中英混合文字，是现代录入者关于字符编码的说明，不是《庄子》正文；相韲处使用了相似代字，原页明确承认，并未精校。
- 《齐物论》“五者园而幾向方矣”等有混合字形与疑字，保留来源字形，不暗中改作规范繁体。

章节文件保留来源页录入层；研读笔记与解释另存。遇到上述段落，要回看原始网页的注记结构，并明确标示正文、来源页校记、现代解释。不得把存在疑字的版本称为权威定本。
