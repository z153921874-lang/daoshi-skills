# 道士 · daoshi

一套以中国经典为资料基础的个人 AI Skill：检索原文、回查出处、对读篇章、整理现实困扰，以及运行梅花易数和紫微斗数的传统计算工具。

它的核心做法是：**先读原文，再作解释；计算交给程序，疑点留在记录里。**

## 能做什么

- **经典研读**：本地全文检索、逐章阅读、引文出处、经文与旧注层次辨识。
- **谈心修身**：先理解现实处境与感受，再酌情结合经典讨论小行动；用户可以明确要求不占卜。
- **梅花起卦**：年月日时与双数起卦，显示本卦、互卦、变卦、动爻和体用。
- **紫微排盘**：固定 `iztro@2.6.1`，输出十二宫、星曜、四化、大限及指定年份流年，记录计算规则。
- **Obsidian 阅读**：原文、研读笔记、相关篇章、疑点与进度相互链接；仓库视图可由工具生成。

## 使用与运行

这是作者本地项目的分享版本，原有 Windows 路径约定为 `E:/国学/道士`，Obsidian 路径为 `E:/Obsidian/道士`。它**不是跨平台一键安装包**。

代码保留原项目结构，部分入口仍按上述绝对路径运行。其他机器应先配置或适配路径；安装工具与验收脚本中的 `C:/Users/USER` 是脱敏占位符，需改为自己的 Codex 技能路径。

本仓库不携带第三方依赖缓存。先安装 Python 和 Node.js，在项目根目录安装 Python 依赖，再在 tools 目录恢复锁定的 Node 依赖：

```bash
python -m pip install -r requirements.txt --target tools/vendor
cd tools
npm ci
node test_divination.cjs
```

在项目根目录执行原文检索：

```bash
python tools/library.py "知止" --book laozi
```

道藏首批有独立检索入口：

```bash
python 扩展/道藏首批/library.py search "宽急"
```

技能文件在 `skill/daoshi`。完成路径适配与本机校验后，可复制到个人 Codex 的 `skills/daoshi` 文件夹，用 `$daoshi` 调用。

**分享版本的个人服务默认未启用。** 原始验收记录反映作者当时的本地检查；路径脱敏、依赖重装和环境变化后，不能把旧发布凭据当成新环境已通过。不要手工把 `enabled` 改成 true。需要重新核对证据、路径、依赖及技能格式，审核通过后再由验收程序生成新的发布凭据。

使用示例：

> $daoshi 最近工作压力很大，先陪我梳理，不用起卦。

> $daoshi 解释道德经第四十四章，引用本地原文并区分现代应用。

> $daoshi 用8和16起卦，展示完整计算过程与本、互、变卦。

## 验证与限制

原项目保存12组基础计算检查、150个五局日位对照、5组古籍与软件规则对读，以及引文、文本层次和五类谈话场景走查。场景检查是人工撰写示例后核对，不是独立模型评测或临床验证。

这些检查验证计算和检索的一致性，**不证明术数能预测人生**。不以命盘推断死亡、疾病、灾祸、出轨、人格缺陷或替用户作重大决定。

谈心定位为传统文化背景下的情绪支持，不冒充持证心理医生。《内经》用于研读，不据古方开药、指导针灸或建议停药。宗教修持文字作为历史文本分析，不提供铅汞丹药、强憋气等操作。

所选网络本有已记录的异文和疑字。新增《度人经》卷五有替代字符，朱熹《考异》页面有疑字及语序错乱，尚待校核。

默认不额外保存倾诉或出生资料，也不提交到排盘网站；本次分享不包含实际咨询档案、个人批注、本机安装记录或依赖缓存。宿主对话记录不在此承诺范围内。
